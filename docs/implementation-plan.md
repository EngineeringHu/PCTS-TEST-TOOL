# PCTS Video Tool Implementation Plan

**Goal:** 在独立目录交付可运行的视频分析、异常复核、双口径计算和Excel导出工具。

**Architecture:** 简单数据类与独立计算；顺序解码提取特征；按轮读取OCR与跟踪指尖；Qt后台任务连接复核界面。

**Tech Stack:** Python、PySide6、PyAV、OpenCV、RapidOCR、MediaPipe、XlsxWriter。

**Spec:** [design.md](design.md)

## Global Constraints

- 不依赖或修改旧方案与演示目录，不提交Git。
- 外部JSON/ROI/人工输入在入口校验；内部按数据类使用。
- 按0基原片索引追溯，计算方式任务内统一，可切换。
- 自动缺失和人工待确认不得用0冒充有效数据，TX保留负值。
- 打包程序运行期不联网下载模型。

## Review Focus

可变帧间隔、相邻轮读数串轮、缺少闪光事件、触摸估计被误认为接触证据、切换计算方式后导出缓存不一致。
